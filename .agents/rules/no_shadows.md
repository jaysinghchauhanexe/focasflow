# UI Design Rule: Zero Shadows Policy

- **CRITICAL**: Do NOT use any drop shadows, box shadows, or elevation glows (`shadow-*`, `box-shadow`, etc.) on any element, card, modal, button, popover, or dropdown anywhere in the project.
- Always use subtle flat borders (`border border-borderToken`), clean background surfaces (`bg-card`, `bg-card-subtle`, `bg-card-muted`), and flat modern layout instead of shadows.
- Maintain flat, clean, peaceful aesthetic across all views and components.
